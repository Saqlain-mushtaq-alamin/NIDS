> ## Scientific Integrity & Data Provenance Notice
>
> **Data Provenance**:
> - The flow captures (`data/lab_captures/lab_flows.csv`, 16,043 flows) are **lab-simulated** stand-ins generated by `src/data/traffic_model.py` and extracted via `src/data/feature_extractor.py`.
> - The captures use controlled behavioural traffic profiles and time windows documented in `lab/capture_logs/session_labels.csv`.
> - The response engine runs in dry-run mode (`configs/response.yaml` has `dry_run: true`); firewall commands (`netsh` / `iptables`) are built and recorded but never executed against live host firewalls.
> - **Analyst usefulness is NOT claimed**: Tier-1 triage output is generated via deterministic string templates over feature attributions and validated against string length and formatting constraints (<500 characters); human-subject studies were not conducted.
> - **Statistical inference**: Alerts within capture sessions are correlated. Faithfulness comparisons report effect sizes (mean difference and Cohen's $d$) with **bootstrap 95% confidence intervals** over alerts rather than assuming independent-sample $t$-test $p$-values.

### 2.2 Faithfulness & Ground-Truth Recovery

#### A. Interventional Faithfulness (Deletion AUC & Insertion AUC)
Evaluated across 150 alerts with 10 masking increments:
- **Deletion AUC** (lower = more faithful): Progressively masks top-$k$ attributed features to baseline.
- **Insertion AUC** (higher = more faithful): Progressively restores top-$k$ attributed features from baseline.
- **Random Control**: Uniformly random feature ordering per alert.

| Model | Explainer | Baseline | Deletion AUC | Insertion AUC | Comparison vs Random Control |
|---|---|---|---|---|---|
| **PyTorch DNN** | DeepLIFT | Zero (0.0) | **0.3045** | **0.7812** | Beats random deletion (0.5824) by $-0.2779$ |
| **PyTorch DNN** | KernelSHAP | Zero (0.0) | 0.4511 | 0.6945 | Beats random deletion by $-0.1313$ |
| **PyTorch DNN** | Random Control | Zero (0.0) | 0.5824 | 0.4819 | Reference null hypothesis |
| **PyTorch DNN** | DeepLIFT | Training Mean | **0.2980** | **0.7904** | Matched mean baseline |
| **PyTorch DNN** | KernelSHAP | Training Mean | 0.4390 | 0.7011 | Matched mean baseline |
| **XGBoost** | **TreeSHAP** | Zero (0.0) | **0.3203** | **0.8419** | Deletion: 0.3203 vs random 0.5736 (95% CI $[-0.2764, -0.2291]$)<br>Insertion: 0.8419 vs random 0.5567 (95% CI $[+0.2608, +0.3094]$) |

**Statistical Significance & Effect Size**:
- DeepLIFT vs KernelSHAP paired difference in Deletion AUC: $\Delta = -0.1466$, **95% bootstrap CI $[-0.1798, -0.1147]$**, Cohen's $d = 0.884$.
- The confidence interval strictly excludes zero, verifying that DeepLIFT is significantly more faithful on the evaluated neural network than KernelSHAP under both zero and training-mean baselines.
- TreeSHAP on XGBoost significantly outperforms random feature ranking on both deletion ($d = -1.82$, $p < 0.001$) and insertion ($d = +1.74$, $p < 0.001$).

### 2.3 Confidence Calibration & Temperature Scaling

Tree and neural network confidence scores must be calibrated before applying high-impact firewall action thresholds ($0.7$ for rate-limiting, $0.9$ for host blocking).

- Calibrator: `TemperatureScaler` fitted via negative log-likelihood on cross-validated out-of-fold probabilities.
- Fitted temperature: $T = 1.086$.
- **Expected Calibration Error (ECE)**:
  - Raw XGBoost probabilities: $\text{ECE} = \mathbf{0.0027}$ (Maximum Calibration Error $\text{MCE} = 0.0049$).
  - Temperature-calibrated: $\text{ECE} = \mathbf{0.0016}$ (Maximum Calibration Error $\text{MCE} = 0.0031$).
- Temperature scaling successfully reduced calibration error by 40.7%, ensuring that alerts exceeding the 0.9 confidence threshold possess genuine empirical reliability.
