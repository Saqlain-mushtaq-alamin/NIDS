## 1. What Was Built

### Cross-dataset evaluation (`src/evaluation/cross_dataset.py`)

`CrossDatasetEvaluator` trains on one dataset and evaluates on another over the
full ordered-pair matrix (3 datasets = 9 pairs, diagonal included).

| Correctness property | How it is enforced | Test |
|---|---|---|
| No preprocessing leakage | Preprocessor is fitted on the *training split* only; the test dataset is transformed with training medians/scaler | `test_test_dataset_does_not_change_training_features` |
| No diagonal shortcut | The diagonal cell is scored on the held-out test split, never on training rows | `test_diagonal_scores_held_out_rows_only` |
| No label-set laundering | Test rows whose label the model cannot emit are excluded **and reported** via `test_coverage` | `test_unknown_test_labels_excluded_and_reported` |
| Predictions stay honest | A prediction outside the trained label set counts as an error, never filtered away | `test_out_of_vocabulary_prediction_is_an_error` |
| No state between cells | A fresh preprocessor and a fresh model per pair | `test_fresh_model_per_pair`, `test_template_preprocessor_is_never_fitted` |
| Defined metrics | `f1` = weighted F1, `macro_f1` = unweighted mean over shared labels; both reported | `test_report_written_with_headline` |

### Multi-seed statistics (`src/evaluation/statistics.py`)

Dependency-free implementations of `paired_ttest`, `wilcoxon`, `mcnemar` and
`bootstrap_ci`, each cross-validated against SciPy in the test suite:

- t-statistic and p-value match `scipy.stats.ttest_rel` to 1e-9.
- Wilcoxon exact p matches `scipy.stats.wilcoxon(method='exact')` to 1e-9.
- McNemar matches `scipy.stats.binomtest` to 1e-12.
- `_t_sf` (regularised incomplete beta, Lentz continued fraction) matches
  `scipy.stats.t.sf` to 1e-10.

**Resolution limit, stated explicitly:** the smallest attainable one-sided exact
Wilcoxon p is `0.5**n`, so 4 seeds can never reject at alpha=0.05 and 5 seeds are
the minimum for the exact test to be capable of rejecting. The CSV `note`
column says so per pair rather than silently reporting "not significant".

### Feature schema and extraction (`src/data/feature_extractor.py`, `configs/feature_schema.yaml`)

- `behavior_core`: 16 domain-invariant flow features.
- `behavior_extended`: 28 canonical behaviour features.
- `identity_columns`: IP, port, protocol, timestamp, session, flow-id columns;
  `assert_behavior_only()` fails loudly if a behaviour schema declares one.
- `align_to_canonical()` maps CIC-IDS2017, UNSW-NB15, LYCOS-IDS2017, CTU-13 and
  lab-captured columns onto the schema, deriving canonical features that no
  single raw column provides (e.g. forward/backward IAT means from a flow-level
  mean, per-direction packet-length std from per-packet count columns).
- Dependency-free libpcap reader, IPv4/TCP/UDP flow aggregation, Zeek
  `conn.log` parser (JSON and TSV) and capture-window session labeler.
  `scapy`/`dpkt` are not installed and are not required.

### Preprocessing (`src/data/preprocessor.py`)

Refactored for this phase: `feature_mode` (`full` / `behavior_only` /
`behavior_extended`), `get_feature_names()`, canonical projection through
`align_to_canonical`, train-only medians and scaler, and a guarantee that
`transform()` recomputes nothing from the frame it is given.

### Scripts

| Script | Purpose |
|---|---|
| `scripts/run_cross_dataset.py` | Full experiment driver: all datasets x modes x models x seeds; writes CSV/JSON/MD artifacts |
| `scripts/generate_sample_data.py` | Regenerates the CIC-IDS2017 and UNSW-NB15 stand-ins |
| `scripts/generate_lab_capture.py` | Generates simulated PCAPs + session labels, or extracts features from real captures |

## 3. Results

Model: `XGBBaseline` (n_estimators=150, max_depth=6, lr=0.05), 5 seeds
(42, 1337, 2024, 7, 99), 9 ordered pairs per mode. 45 model fits per mode.

### Headline

| Quantity | `full` | `behavior_only` |
|---|---|---|
| Mean in-domain macro-F1 | 0.9882 | 0.9549 |
| Mean cross-domain macro-F1 | **0.0336** | **0.0381** |
| Mean dF1 (in - cross) | **+0.9546** | **+0.9168** |
| Cross-domain F1 retention | 3.4% | 4.0% |
| Paired t-test (per-pair deltas, n=6) | p = 1.11e-09 | p = 3.28e-08 |
| Wilcoxon exact one-sided (n=6) | p = 1.56e-02 | p = 1.56e-02 |
| Bootstrap 95% CI on mean dF1 | [+0.9388, +0.9705] | [+0.8832, +0.9504] |
| Cross-domain pairs worse than in-domain | 6 / 6 | 6 / 6 |
| Pairs significant at alpha=0.05 | 6 / 6 | 6 / 6 |
| Mean test-label coverage | 87.5% | 87.5% |

### Per-pair macro-F1 (mean over 5 seeds)

| Train | Test | `full` | `behavior_only` |
|---|---|---|---|
| cic-ids-2017 | cic-ids-2017 (in-domain) | 0.9863 +/- 0.0047 | 0.9587 +/- 0.0071 |
| cic-ids-2017 | unsw-nb15 | 0.0000 +/- 0.0000 | 0.0000 +/- 0.0000 |
| cic-ids-2017 | lab-captured | 0.0477 +/- 0.0000 | 0.0477 +/- 0.0000 |
| unsw-nb15 | cic-ids-2017 | 0.0533 +/- 0.0298 | 0.0667 +/- 0.0000 |
| unsw-nb15 | unsw-nb15 (in-domain) | 0.9933 +/- 0.0063 | 0.9320 +/- 0.0254 |
| unsw-nb15 | lab-captured | 0.0532 +/- 0.0298 | 0.0665 +/- 0.0000 |
| lab-captured | cic-ids-2017 | 0.0476 +/- 0.0000 | 0.0476 +/- 0.0000 |
| lab-captured | unsw-nb15 | 0.0000 +/- 0.0000 | 0.0000 +/- 0.0000 |
| lab-captured | lab-captured (in-domain) | 0.9851 +/- 0.0018 | 0.9739 +/- 0.0013 |

The absolute cross-domain values land in the 0.00-0.07 band that the research
proposal (section 3.2) documents for cross-dataset IDS evaluation, so the
pipeline reproduces the expected collapse. Two zero cells are complete
label-set mismatches in *both* directions (a model trained only on
CIC-IDS2017 has no `Other`; a model trained on `lab-captured` has no `DDoS`
classifier that generalises), and the remaining cells are near-chance on the
shared labels.

### Gate status

| Gate | Requirement | Result |
|---|---|---|
| G2 (core) | Cross-domain F1 < in-domain F1 | **PASS** - 0.0336 < 0.9882, all 6 cross pairs negative, all significant |
| G2 mitigation | Behaviour-only features improve transfer | **WEAK PASS** - +0.0044 cross-domain macro-F1 (0.0336 -> 0.0381); direction is right, magnitude is negligible |
| FR6 | 5 seeds, paired test, CI | **PASS** - 5 seeds, t-test and exact Wilcoxon, bootstrap CI on file |

The mitigation result is a genuine (negative-leaning) finding, not a
disappointment to be hidden: **removing identity columns does not rescue
cross-dataset transfer.** The gap is not caused by IP/port leakage but by the
features themselves shifting meaning between capture environments, which is the
argument the proposal makes and the direction Phase 3 must now address.

## 6. Bugs Found and Fixed During This Phase

1. **`load_dataset` destroyed the unified label column.** `_apply_label_mapping`
   dropped `label_column` after writing the mapped values, so for datasets whose
   label column *is* `label` (lab-captured) the result was deleted outright.
   Mapping is now applied in place when the column is already `label`, and
   already-unified labels are preserved instead of collapsing to `Other`.
2. **UNSW-NB15 label column misnamed in the generator.** The stand-in emitted
   `attack`/`label` (0/1) instead of the registry's `attack_cat`, so the loader
   fell through to the raw 0/1 column and the taxonomy never applied.
   Regenerated with both `attack` and `attack_cat`, matching the real dataset.
3. **`to_numpy()` returned a read-only view** under pandas 3 + pyarrow, so
   median imputation raised `ValueError: assignment destination is read-only`.
   `_fillna` now copies explicitly.
4. **`StringMethods.count()` no longer accepts `regex=False`** in this pandas
   build, breaking flag counting. Replaced with `str.map` counting.
5. **`dport` was not in the identity denylist**, so a UNSW destination port
   reached the model as a feature.
6. **Diagonal leak in the first harness draft.** The diagonal cell was scored on
   the full frame (including its own training rows). Now the held-out split is
   used.
7. **Ragged pairing in the overall test.** `analyze()` paired 3 diagonal cells
   against 6 off-diagonal cells and raised. The unit of analysis is now the
   ordered pair (one matched delta per pair).
8. **Wilcoxon normal approximation used the wrong tail.** For n > 25 the
   two-sided p doubled the *upper* tail, making a maximally significant result
   return p ~ 1.0. Now doubles the lower tail.
9. **`timestamp_start` / `timestamp_end` / `session_id` reached the model** in
   `full` mode. Added to the identity denylist in both the preprocessor and
   `configs/feature_schema.yaml`.

## 7. Limitations and Next Steps

1. **All data is synthetic.** The experiment's *method* is validated; its
   *magnitudes* are not. Re-run on real CIC-IDS2017, UNSW-NB15 and real lab
   captures before any external claim.
2. **Synthetic domains are separable by construction.** Each stand-in was
   generated with its own profile parameters, so cross-domain collapse is
   partly baked into the data rather than discovered by the model. This biases
   the measured gap *upward* and must be stated wherever these numbers appear.
3. **`Other` is a taxonomy artefact.** UNSW-NB15's Fuzzers/Generic/Analysis
   collapse to `Other` via the Phase 1 mapping, and that label exists in no
   other domain, so every `Other` row is excluded from cross-domain scoring.
   This is the largest single driver of the 87.5% mean coverage.
4. **Phase 3 has a real problem to solve.** Behaviour-only features barely move
   the needle (+0.0044). The next phase should test whether *calibration*,
   *per-dataset normalisation*, or *domain-adversarial training* moves transfer
   more than feature selection did.
5. **`behavior_extended` is implemented but not yet benchmarked** - run
   `--modes behavior_extended` to see whether the 12 extra behavioural features
   transfer better than the core 16.
6. **One model family.** Only `XGBBaseline` was run end-to-end. The `rf`
   factory is wired up and ready.
